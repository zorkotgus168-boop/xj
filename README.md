# 巩留库尔德宁 H5 网页设计方案与交互系统

> **设计主题：** 天山绿谷·云杉秘境——巩留库尔德宁  
> **项目定位：** 微信移动端文旅沉浸式传播 H5，兼具“景区科普”、“实景导览”、“民族文化”、“生态研学”四大属性。

---

## 🌟 核心视觉与技术亮点

1. **色彩与质感设计：**
   - **云杉墨绿** (`#133E2B`) + **草原嫩青** (`#4E8752`) 作为主基调；
   - **雪山冷白** (`#F5F9F7`) 与 **哈萨克赭石暖金** (`#C67D43`, `#DF9B58`) 作为高光点缀；
   - 融入轻量化哈萨克传统角状刺绣花纹边角装饰，不抢风景主体，文化韵味深厚；
   - 界面采用毛玻璃拟态（Glassmorphism），层次分明，观感高级。

2. **交互体验与动效：**
   - **平滑竖向翻页系统：** 模拟漫步天山山谷的上下平滑位移，并支持桌面滚轮、触屏手势、右侧指示器及抽屉全景导航；
   - **原生自然白噪音与冬不拉纯音合成器（Web Audio API）：** 无需下载大体积外部音频，纯原生合成轻柔天山山风白噪音与两弦冬不拉五声音阶拨弦乐，支持随时一键静音/开启；
   - **交互式手绘景区地图：** 矢量手绘峡谷河流，齐梦德观景台、云杉王、十里画廊、云上草原、阿尤赛观景台、喀峰大本营 6 大热点点位联动，点击发光点位即时呼出图文详情与海拔指引；
   - **一谷四季交互切换：** 春·花海、夏·林海、秋·彩林、冬·雪国大图切换，配以经典诗意文案；
   - **研学生态互动问答：** “为什么一棵雪岭云杉就是一座微型水库”，即时选择即时反馈；
   - **游客打卡留言墙：** 实时发表对天山与库尔德宁的寄语，数据自动保存至本地缓存；
   - **专属旅行纪念明信片生成（HTML5 Canvas）：** 动态将高清实景、巩留官方邮戳、专属寄语绘制成纪念海报，支持一键下载保存相册；
   - **中英双语国际化切换（i18n）：** 适配高中/大学生态研学课题及对外文旅推介。

## 📱 8大页面完整架构与文案明细

### 第1页｜封面页（Cover）
- **核心标题：** 天山绿谷 · 云杉秘境 ｜ 巩留 · 库尔德宁（KURDENING · TIEN SHAN）
- **权威认证徽章：** 世界自然遗产 · 新疆天山核心区 ｜ 国家4A级景区
- **标签：** 🌲 雪岭云杉的故乡 ｜ 🏔️ 罕见南北横向阔谷 ｜ 🏕️ 哈萨克游牧风情
- **导语：** 欧亚大陆野生生物天然基因库，这里汇聚天山至为壮丽的雪峰、林海与高山草甸。
- **动效：** 缓慢流动的山间云雾 Canvas 粒子动画，金光脉冲“开启秘境之旅”按钮。

### 第2页｜秘境认知（About Kurdening）
- **章节名：** CHAPTER 01 · 秘境认知
- **核心文案：**
  1. *横沟奇观：* 罕见南北走向阔谷，截留大西洋吹来的暖湿水汽，降水充沛。
  2. *雪岭云杉之王：* 西天山国家级自然保护区核心，中国森林蓄积量最高的高山针叶林区。
  3. *生态基因宝库：* 喀班巴依峰（4257米）雄踞谷底，冰川融水汇聚成库尔德宁河。
- **数据栏：** 4257m 喀班巴依峰 ｜ 1000+年 云杉王树龄 ｜ 100% 世界自然遗产核心区

### 第3页｜风光景点漫游（Scenic Tour）
- **手绘地图 6 大点位：**
  - **齐梦德观景台（2150m）：** 雪山、云杉、草原同框的“神级机位”。
  - **千年雪岭云杉王（1850m）：** 树高近50米、胸径数人合抱的高山巨木。
  - **十里画廊（1600m）：** 沿河谷自驾公路，碧流浅滩，牛羊成群。
  - **云上草原（2300m）：** 高空草甸，五彩花毯，策马驰骋。
  - **阿尤赛观景台（2450m）：** 远眺喀班巴依峰冰川，秋日彩林最佳观赏位。
  - **喀峰大本营（2800m）：** 纯净星空与冰川科考基地。

### 第4页｜一谷四季（Four Seasons）
- **春（4-5月）：** 顶冰花破雪盛放，野杏花次第铺展，谷水潺潺。
- **夏（6-8月）：** 浓荫蔽日千峰翠，平均气温20℃~25℃，避暑天堂。
- **秋（9-10月）：** 泼墨彩林，金黄桦木与墨绿云杉层林尽染，野苹果飘香。
- **冬（11-3月）：** 银装素裹，雾凇挂枝，水墨雪山，静谧圣境。

### 第5页｜人文风情（Kazakh Nomadic Culture）
- **冬不拉与阿肯阿依特斯：** 草原弹唱对歌会（国家级非遗）。
- **白毡房、咸奶茶与手抓肉：** 会呼吸的草原居所，热气腾腾的游牧待客礼仪。
- **喀班巴依英雄传说与大转场：** 英雄主峰与千年游牧迁徙文明活化石。
- **赛马叼羊与黑走马舞：** 速度与力量的较量，篝火摇肩舞蹈。

### 第6页｜游玩攻略（Travel Guide）
- **交通路线：** 巩留县城至东门约60公里（车程约1-1.5小时），实行旺季单向环线通行管制。
- **门票与开放时间：** 夏秋 08:30-20:00，一日精华游与两日深度星空徒步推荐。
- **特色食宿：** 森林木屋民宿、星空毡房、手抓肉、巩留野苹果果酱。
- **出行装备与自然保护守则：** 严禁野外用火、无痕山野（LNT）垃圾随身带下山。

### 第7页｜自然研学（Ecology Education）
- **微型水库原理：** 林冠截留（15%-30%降水）+ 海绵苔藓层（蓄水自重3-5倍）+ 庞大深根系涵养地下水。
- **物种名录：** 雪豹、金雕、天山马鹿、野生古果林。
- **互动答题：** 问答交互，即选即批改。

### 第8页｜相约天山·文旅打卡与分享（Share & Postcard）
- **标语：** 赴一场天山之约，遇见库尔德宁。
- **明信片生成：** Canvas 绘制专属纪念明信片与邮戳。
- **留言打卡墙：** 游客即时留言祝福，持久化保存。
- **官方二维码与文旅标识：** 巩留县文旅局官方服务咨询。

## 🚀 本地运行与体验指南

1. **直接启动网页：**
   在项目根目录下运行任意 HTTP 服务器（如已启动的端口 `8080`）：
   ```bash
   python3 -m http.server 8080
   ```
2. **在浏览器中打开：**
   访问 [http://localhost:8080](http://localhost:8080)
   - **手机/微信打开：** 完全自适应手机屏幕比例，支持触摸上下平滑滑动；
   - **电脑端打开：** 自动显示为高质感移动端手机框体，支持鼠标滚轮与键盘上下键控制，四周衬托高雅天山背景。
